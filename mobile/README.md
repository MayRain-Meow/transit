## 本次更新

前台手机通知横幅、音量条、短暂失焦不暂停，也不取消拉线。Web只在页面实际隐藏、离开或冻结时中断；Android使用Capacitor Activity.onStop发出的appStateChange=false，不再订阅临时onPause。后台暂停保存，回来保持暂停、手动继续。继续及重开不再依赖document.hasFocus；长帧间隔不被误判成切后台，不补算离开时间。

动画回调统一为一个：直接render和frame结束都取消已有游戏回调，保证只保留一条链。更新/事件异常有本地诊断记录，停止继续模拟，不再写入异常状态，显示独立恢复入口；返回最近存档的选图页后可继续或重新开始。重开/加载清理旧手势、指针、桥梁草稿、弹窗、预览及待编辑状态。此保护针对可捕获JS异常，不能修复系统级WebView卡死或同步无限循环。

公交只能从同一条线路的一端拖向另一端闭合，至少三座不同真实城市；中途重复节点不能形成局部环线。移除专用闭合/解除按钮。保留原回拉删路、手动架桥和确认预览。选中线路后，地图拖动仅编辑这条线路；其他线路专属城市或线段不会偷偷切换编辑对象，可拖动地图。应用/取消结束草稿，选择新线路或新建线路可明确切换对象。

底部交通网络的标题、新建、展开分别分配宽度；编辑摘要与取消在第一行，应用修改单独占第二行，避免额外按钮挤成竖排。

## 构建与验证

需要JDK21、Android SDK36、Build Tools35/36、Node22以上。进入mobile，npm ci、npm run sync:android、npm run verify；然后设置JAVA_HOME/ANDROID_HOME并运行python3 scripts/build-android.py。也可在android内运行bash gradlew assembleDebug lintDebug。

APK输出android/app/build/outputs/apk/debug/app-debug.apk。原签名私钥不入库；缺少时本地Android调试签名不能覆盖原分发包。APK和私钥均不上传GitHub。
