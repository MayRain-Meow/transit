# 网页竖屏适配更新（2026-11-08）

本次先更新网页，APK不重新打包。

- 地图方向固定，不再因竖屏自动旋转90度；保留新版PR的三个中心和面板交互。
- 活动邀请一次只挂载一张卡，翻页栏固定在卡片下方；左右滑动、上一张/下一张切换均保留翻牌状态，不会承接任务。五星、六星特效沿用。零欠款与空结算不占据卡牌页。
- 只在持有理财或股票时产生每日持仓简报；只持理财显示理财页，持股票显示股票页；未买入时行情继续运行。农业仅在实际收获时通知。设施开放及中级农田首次可用改为一次轻提示。
- 网页同步中级及以上居住城市的农田门槛；旧存档已播种的小镇农田保留收获及记录，不能再次在小镇续种。
- 拉线遇到地震受损路段，在报价栏直接显示状态、费用、工期和维修按钮。查看不扣款，点击只支付维修，不提交拉线；重复点击不扣第二次。资金不足、在途车辆待清空和维修中均明确说明。
- 河流按“先河岸层、再水面层”的顺序统一绘制整个河网，消除支流河岸覆盖干流水面的接缝。新开局保存平滑采样河道，绘制/刷城/架桥/跨河判定共用同一条中心线；支流末端投影焊接至干流。旧档不移动物理河道、城市或桥头。
- 修复多河网及曲线河道建桥的旧左右岸标签误判，实际跨河/山地/长度校验仍保留。
