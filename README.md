地图只用翻土、幼苗、作物长高、成熟和收获图形表现变化。点击农田或城市详情可进入种植面板；运营中心和收支账本提供农业总览、每城记录和累计净利润曲线。已实现盈亏仅计完成轮次，正在种植的投入单独列示。

同一时点成熟的农田合并在一张通知中；到账、待确认通知、记录和曲线一起存档。收获时整个模拟暂停，确认后恢复此前运行状态；此前已暂停则保持暂停。暂停及离线不推进日期，不重复到账。若有维护欠款，收获收入沿用现有自动偿债规则。
