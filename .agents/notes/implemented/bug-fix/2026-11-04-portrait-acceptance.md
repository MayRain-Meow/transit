# Agent Note: 0.4 竖屏验收与取景边界

Status: implemented

## Problem

`6b559a7` 将 0.4 改为手机优先布局。验收发现：

- 390×844 下，12月30日、资金 ¥12345.67 时单行顶栏宽 416px，帮助按钮越出屏幕。
- 竖屏 `fit()` 将范围限制在初始地图内；模拟城镇 (-650,-200) 的屏幕 x 为 -391px，不能通过“查看全图”找回。
- 资金按钮用伪元素扩大点击区，但按钮按下缩放会改变伪元素的包含块，实际点击资金数值没有打开账本。
- 无车辆线路的详情每次刷新都追加“车辆运行控制”：原去重条件依赖只在有车辆时存在的 `setService(`。

## Decision

- 手机竖屏使用两行顶栏：第一行日期、资金和生命，第二行播放、速度、任务和帮助。
- 竖屏取景使用实际城镇范围及边距，不把远城裁回初始地图；缩放下限允许回到当前全图范围。
- 计算可用地图高度时同时考虑线路面板和已打开的详情，横竖屏切换后城镇仍在面板上方。
- 资金区域本身是原生按钮，保留 `finance`、`points`、`maintenance-estimate` ID 与账本回调。
- 详情按 `service-list` 容器去重；线路无车也只显示一组运行控制。

## Alternatives considered

- 继续缩小单行顶栏字号或隐藏帮助：会降低可读性和功能可达性，不采用。
- 固定初始地图边界：开局好看，但会藏起正常解锁的远城，不采用。
- 给资金容器另加点击回调：会保留伪元素和重复入口，原生按钮更简单。
