# Agent Note: 竖屏地图旋转与竖屏特化（基于 0.5）

Status: implemented

## Problem

用户验收 0.4.1 后反馈：底栏过高、地图不适合竖屏、新地点交互手感差、线路端点延长手感差、冗余功能多。上游随后发布 0.5（城市活动、新城 30 秒自动开放），用户要求合并后再按竖屏优化地图、事件标记、地形和字体的观感。

审计结论：

- 世界是 1200×710 的横向地图，新城只出现在 `y 265–620` 的横向带内（约 2.4:1），竖屏可用区域约 0.6:1。无论怎么取景，城市都挤成中间一条细带。
- 竖屏底部被两块占据：线路面板（约 150px）和 58px 的底部按钮栏，合计约 240px。
- 远城出现时 `spawnCity` 会调用 `fit()`；旧的 `tick` 在新城出现于屏幕外时会 `animateFit()`。两者都会把镜头拉走。
- 延长线路要先选中线路再拖端点城市，一次只能接一座城；多线共用的城市会先弹出选线面板。
- 运营中心的标题被 0.5 的活动区块挤到下方，「城市任务」「收支账本」与底部按钮栏、顶栏资金入口重复。工程面板对每座城市都列「建气象站 / 枢纽 / 检修中心」，与城市详情里的按钮重复。帮助末尾追加了大段版本说明。
- 上游的「撤回建线」浮条（`z-index:45`）会盖住弹窗和顶部通知。

## Decision

用户选择「竖屏旋转 90°」（另一个选项是保持方向、只调整取景）。

- **引擎（game.js）**
  - 新增 `view.rot`：竖屏为 1，顺时针旋转 90°，海在下方，北岭在右侧。
  - `toWorld` 支持旋转；新增 `toScreen`。`render` 统一施加旋转，零散的屏幕坐标计算全部改用 `toScreen`。滚轮缩放改为按屏幕空间锚定，与旋转无关。
  - `text()`、`roundBody()` 读取当前变换矩阵：旋转时绕自身锚点转回正立。城市装饰整组绕城市中心转正（`uprightAround`），建筑和树用 `uprightHere`。
  - 地形缓存分横、竖两份；竖屏单独画朝上的层叠山峰，海浪改为水平走向。
- **取景（world.js）**：`fit()` 在旋转时交换横竖跨度。越界回弹改为屏幕空间判断。远城出现时不再自动取景。
- **体验层（ux.js）**
  - **城市附属标签**：任务角标、活动/商演标记、学校/检修图标、开放倒计时，按「80 单位内最近城市；否则正下方 150 内的城市」找到所属城市，再绕它转正（城市间距至少 145）。这些包装在 `DOMContentLoaded` 后挂上，因为 `events.js` 在 `ux.js` 之后加载。
  - **端点把手**：每条线路两端各有一个把手，选中的线路高亮。从把手拖出可连续接多座城，回拖可撤回；不需要先选线，多线城市也不弹选线面板。点一下把手不拖动 = 选中线路。
  - **屏幕边缘指示**：屏幕外的待开放新城（带倒计时）和告急城市显示在边缘，点一下平滑移过去并打开城市面板。镜头不再自动移动。
  - **标签与字体**：缩小查看时标签字号最多放大 1.35 倍；画布文字改用 Noto Sans SC。
  - **面板整理**：运营中心标题置顶并删除重复入口；工程的逐城设施列表合并为一行汇总；帮助里的版本说明收进「版本新增」折叠组。
- **CSS（竖屏）**
  - 线路面板变成一行可横向滑动的线路胶囊，配「＋」和「⌖」两个按钮；底部按钮降为 50px，底部区域总高约 120px。
  - 隐藏横屏建议和顶栏里的维护预估。
  - 「撤回建线」浮条移到通知下方居中，弹窗打开时隐藏。

## Alternatives considered

- **保持方向、只调取景**：仍然是一条横带，需要频繁左右拖动，用户未选。
- **按竖屏重新生成世界**：会改变地形、平衡和存档语义，不采用。
- **旋转时交换城市坐标、不旋转画布**：地形函数（`river(y)`、山体判定）依赖真实坐标，渲染期间临时交换坐标容易出错。
- **把附属标签函数整段复制成竖屏版**：会随上游改动而漂移；现在用「执行期间临时替换 `text` / `roundBody`」的包装，上游改动后无需同步。

## Verification

日期 2026-11-05，基于 `origin/main` `e4116e1`（0.5）合并后的提交。

- `node tests/*.cjs`：6 套全部通过（含上游新增 `activities.cjs`）。`ux-layer.cjs` 新增 3 项：旋转后坐标往返误差小于 1e-9 且城市都在可用区域内；尾端把手连续延长、回拖撤回；首端延长按行进顺序前插。`portrait-layout.cjs` 改用 `toScreen` 计算屏幕坐标。
- CDP 真实触摸（390×844，旋转）：点城市选中；拖线建线；拖尾端把手接新城，「建设 ¥71 / ¥87」一键延长；点把手选中线路；屏幕外新城指示点击后移到并打开；双指缩放 1.1→1.83。
- 截图检查：390×844（1x 与 2x）、844×390、1440×900，以及运营 / 工程 / 采购 / 账本 / 帮助 / 任务 / 城市 / 线路面板。横屏和电脑端方向与布局不变。
- 未做 Android/iOS 真机验证。

## Consequences

- 新增屏幕坐标计算一律用 `toScreen` / `toWorld`，不要手写 `x*view.scale+view.x`。
- 新的「城市 + 偏移」绘制函数，如果要在旋转下保持正立，需要加进 `uxWrapLateDrawers` 的名单，或直接接收城市参数后使用 `uprightAround`。
- 地形缓存键为 `terrainCache[0|1]`，把 `terrainCache` 置为 `null` 会同时失效两份。

## Follow-up: 城市详情不遮挡、地图贴图与文字减负（2026-11-05）

用户反馈：点开城市后，详情遮挡地图；房子、标签、角标互相叠压，既不美观又影响操作。

- **详情面板两档**（仅竖屏）：
  - 新选中的对象先以「半展开」出现：`min(36dvh,300px)`，显示标题、关键数字和主要操作，底部有渐隐和「上滑查看全部」提示。
  - 上滑或轻点顶部抓手展开为「全展开」（可滚动）；下滑先收回半展开，再下滑关闭。
  - 每次切换后，用 `uxFrame` 把选中的城市、线路或车辆框进面板上方的可见区域：只平移，必要时缩小，从不放大。
  - 气象站、检修中心预览时自动收成半展开，并把整个覆盖圆框进可见区域。
  - 原 `world.js` 中只做纵向平移的避让逻辑已删除，统一由 `ux.js` 处理。
- **地图减负**（`game.js` 新增三个开关，默认值保持原行为）：
  - `TEXT_HALO`：9px 及以上的标签加柔和描边，不用底框也清楚；
  - `QUEUE_SHOWN=12`：候车方块最多两行，超出部分显示「+n」；
  - `ART_ALPHA`：拉线、建桥或选中线路时，城市建筑淡化到 42%。
- **任务角标**：缩小视图（scale<0.9）下，进度为 0 和「繁荣」的角标隐藏；选中城市或奖金到账时始终显示。
- **端点把手**：未选中线路的把手改为更小、更淡（半径 5.5、透明度 0.38）。
- **叠放**：全展开时隐藏「撤回建线」浮条，提示消息改到顶部；全展开面板让出约 56px 给提示。
- **验证**：
  - 6 套测试通过；
  - CDP 真实触摸：点城市进入半展开且城市可见，上滑全展开，下滑收回，点抓手展开，再下滑关闭；
  - 2x 截图覆盖：缩小视图、城市半展开与全展开、气象站预览框住整圆、线路半展开、拉线时建筑淡化。
- **状态文字下移**：`TIMERS_BELOW` 开启后，接入、保护、即将成长、待接入倒计时显示在城市名下方的副标题位置，不再压住建筑；「拥挤 Ns」告急仍在城市上方，用红色。`SUBTITLE_MIN_SCALE=.8`：缩放低于 0.8 时隐藏「类型 · 等级」副标题，选中的城市除外。两个开关未开启时，原上游代码原样执行。
