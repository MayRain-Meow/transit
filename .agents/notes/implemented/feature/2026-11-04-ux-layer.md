# Agent Note: 0.4 体验层（竖屏优先的建线与界面统一）

Status: implemented

## Problem

用户验收 `3ac1882` 后反馈：

- 大量弹窗仍是「卡片套卡片」的大圆角矩形（采购、任务、运营、工程、城市详情等）。
- 建线要过两层弹窗：「新建线路」先弹出交通方式选择，拖线后点「查看报价」再弹出「建设报价」确认。
- 要求审计全部功能，竖屏下的核心玩法优先做到最顺手；授权弱化边缘功能。

审计另发现：

- 资金显示为 `¥5580.62`：维护费按小数扣除。
- 竖屏两行顶栏占 112px；任务入口和帮助挤在第二行。
- 撤销线路使用浏览器原生 `confirm()`；城市面板第二个按钮被旧规则渲染成主按钮（「交通枢纽」显得像推荐操作）。
- 触屏上城市与线路的点击半径沿用鼠标值（21px / 12px）；拉线时目标城市在屏幕外无法到达。
- 欢迎页与帮助是整段文字，版本说明链接散落在游戏内多个弹窗。

## Decision

新增 `dist/test04/ux.js`，在 `economy.js` 之后加载，只改界面与操作，不碰经济参数、存档键和模拟规则：

- **建线**：「＋ 新建线路」直接进入拉线（沿用上次的交通方式），不再弹窗选择。底栏依次显示交通方式切换（只列已解锁、有空位的方式）、途经城市、分项报价（线路 / 桥隧 / 首辆车 / 建成后余额）和 ↶ 撤销上一站。按钮显示「建设 ¥X」，点一下即建成。报价确认仍然存在，只是从弹窗移到了按钮上，`AGENTS.md` 已同步。
- **线路面板**：重写为表头（色条、名称、✎ 改名改色、×）＋ 车辆步进器（− 回收；＋ 有库存则派车，没有则直接购买）＋ 站点胶囊（× 摘站，沿用 8 秒撤销）＋ 车辆方案列表 ＋ 道路升级和撤销线路。撤销线路改为两次点击确认，确认状态在面板刷新后保留。旧的「拖动改线」按钮只弹一句提示，已删除，改为常驻提示文字。
- **弹窗**：竖屏改为底部面板，标题栏吸顶，带拖动把手，可下滑关闭，点背景也能关闭（仅限带 × 的弹窗）。旧的卡片类（`infra-card`、`task-cities`、`city-mission`、`product`、`reward`、`finance-summary`）统一改为分隔线列表。英文眉标在标题栏中隐藏，游戏内的版本说明链接隐藏（欢迎页和帮助页保留）。
- **欢迎页、帮助、任务、采购**：重写内容。欢迎页改为三条要点，「重新开始」需两次点击。帮助改为五个可折叠分组。任务改为可点击定位的列表，按进度排序。采购改为列表，未解锁的交通方式显示解锁条件。
- **上游兼容**：合入 `7bf3c63` 的商店加车厢功能。体验层采购入口直接复用 `shopTrainCarsHTML()` 与 `purchaseTrainCar()`，保留逐车选择、容量变化、价格、资金检查、过期点击保护和 8 节上限；样式沿用单列平铺列表。不能仅合并文件而保留旧的体验层 `shop()`，否则最后加载的覆盖会隐藏上游入口。
- **竖屏顶栏**：恢复单行（62px）。资金只显示整数元，「任务」移到底部，成为 4 个等宽按钮之一，位于拇指区。`3ac1882` 的两行方案是为了避免溢出，现在溢出的两个来源（五位数加两位小数、任务按钮）都已移除。
- **触屏**：城市点击半径 30px，线路点击容差 18px（通过 `globalThis.HIT_PX/ROUTE_PX` 注入 `hitCity` / `routeHit`）。拉线、改线时手指靠近屏幕边缘，地图自动跟随滚动。加站和建成时短振动（仅触屏设备）。竖屏的提示消息显示在当前底部面板上方。

## Alternatives considered

- **重写全部生成弹窗的函数**：改动面太大，而且原代码依赖多层字符串替换。最终只重写核心界面（线路面板、任务、采购、欢迎、帮助），其余靠统一的 CSS 拉平。
- **保留报价弹窗、只在底栏加「直接建设」**：两个入口会让人困惑。按钮上已经标明金额，单一入口更清楚。
- **保留两行顶栏**：会多占 52px 地图高度，与「竖屏玩爽」的目标相悖。

## Consequences

- 新的界面改动应放在 `ux.js`。原脚本里被覆盖的界面函数仍然保留，作为未加载体验层时的回退。
- 弹窗统一靠 CSS 拉平。如果新弹窗沿用旧类名，会自动得到列表样式；新的主操作请用 `.primary`。
- `tests/portrait-layout.cjs` 不加载 `ux.js`，校验的是基础层的取景；体验层的回归由 `tests/ux-layer.cjs` 负责。
